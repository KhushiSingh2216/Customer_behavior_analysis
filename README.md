# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior using Python, PostgreSQL, and Power BI. The objective is to identify customer purchasing patterns, understand product preferences, evaluate subscription trends, and generate actionable business insights.

The project follows an end-to-end data analytics workflow, starting with data loading and exploratory data analysis in Python, followed by data cleaning, SQL-based analysis in PostgreSQL, and interactive dashboard development in Power BI.

A detailed analytical report and presentation were also created to communicate the findings and business recommendations.

## 📊 Dataset Description

The project uses a Customer Shopping Trends dataset containing **3,900 customer transactions and 18 original columns**.

### Key Features

- **Customer Information:** Customer ID, Age, Gender, Location.
- **Purchase Details:** Item Purchased, Category, Purchase Amount, Season, Size, Color.
- **Shopping Behavior:** Subscription Status, Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases.
- **Customer Experience:** Review Rating and Shipping Type.

**Data Quality:** The original dataset contained 37 missing values in the Review Rating column, which were handled during data cleaning.

## 🔄 Project Workflow

### 1. Data Loading & Exploration (Python)

- Imported the dataset using Pandas.
- Examined the first few records using `head()`.
- Checked dataset structure using `info()`.
- Generated descriptive statistics using `describe()`.
- Identified missing values and examined data quality.

### 2. Data Cleaning & Preprocessing

Performed the following data preparation activities:

- Handled 37 missing values in the Review Rating column using category-wise median imputation.
- Standardized column names into lowercase snake_case format.
- Renamed columns for better readability.
- Created an `age_group` column using age-based quartiles.
- Created `purchase_frequency_days` by mapping purchase frequencies to numerical day values.
- Checked whether `discount_applied` and `promo_code_used` contained redundant information.
- Removed the redundant `promo_code_used` column.

### 3. PostgreSQL Database Integration

- Connected the cleaned dataset with PostgreSQL.
- Loaded the processed DataFrame into the database.
- Used SQL queries to perform structured business analysis.
- Applied aggregation, filtering, grouping, CASE statements, CTEs, and window functions.

### 4. SQL Business Analysis

Executed 10 SQL queries to answer important business questions:

1. Revenue generated by male and female customers.
2. Customers who used discounts but spent above the average purchase amount.
3. Top 5 products based on average review ratings.
4. Average purchase amount comparison between Standard and Express shipping.
5. Revenue and average spending comparison between subscribers and non-subscribers.
6. Products with the highest percentage of discounted purchases.
7. Customer segmentation into New, Returning, and Loyal customers.
8. Top 3 most purchased products within each category.
9. Subscription behavior among repeat buyers.
10. Revenue contribution by age group.

### 5. Power BI Dashboard

Developed an interactive Customer Behavior Dashboard in Power BI to present important business metrics and trends.

**Dashboard Highlights:**

- Total number of customers.
- Average purchase amount.
- Average customer review rating.
- Customer distribution by subscription status.
- Revenue by product category.
- Sales by category.

## 📈 Key Results & Insights

The analysis revealed several important business insights:

| Metric | Result |
|---|---:|
| Total Transactions | 3,900 |
| Loyal Customers | 3,116 |
| Returning Customers | 701 |
| New Customers | 83 |
| Average Purchase Amount | $59.76 |
| Average Review Rating | 3.75 / 5 |
| Subscription Adoption | 27% |
| Non-Subscribers | 73% |

### Major Findings

- **Customer Loyalty:** Loyal customers represent approximately 80% of the customer base.
- **Revenue Contribution:** Clothing is the leading revenue-generating category.
- **Age Group Analysis:** Young adults contribute the highest revenue.
- **Subscription Opportunity:** Only 27% of customers have subscriptions, indicating an opportunity to improve subscription adoption.
- **Discount Analysis:** Hats, Sneakers, Coats, Sweaters, and Pants show high discount dependence.
- **Product Ratings:** Gloves, Sandals, and Boots are among the highest-rated products.
- **Shipping Analysis:** Express shipping customers have a higher average purchase amount than Standard shipping customers.

## 💡 Business Recommendations

Based on the analysis, the following recommendations were identified:

1. **Improve Subscription Adoption:** Introduce exclusive benefits and incentives to encourage more customers to subscribe.
2. **Strengthen Customer Loyalty:** Reward repeat customers through loyalty programs.
3. **Optimize Discount Strategies:** Review discount policies to balance customer demand and profit margins.
4. **Improve Product Positioning:** Promote highly rated and frequently purchased products.
5. **Targeted Marketing:** Focus marketing campaigns on high-revenue customer segments and product categories.
